# PHASE 7 — ML IMPLEMENTATION REPORT

## 1. ML USE CASE

### Prediction Target
**Congestion Level** (LOW / MODERATE / HIGH) and **Estimated Waiting Time** (minutes) for a given procurement centre + time slot combination.

### Why ML is Useful
Farmers visiting procurement centres often face unexpected long waiting times because they don't know which time slot is likely to be crowded. The ML model analyzes historical booking patterns to predict congestion before the farmer arrives, helping them choose the optimal time slot.

---

## 2. DATA

### Historical Records Used
- **Source**: `data/bookings_queue.csv` (generated by `generate_data.py`)
- **Total Bookings**: 500 records
- **Unique Centres**: 50 procurement centres
- **Crops**: Paddy, Groundnut, Maize, Cotton, Soybean
- **Time Slots**: Hours 9-16 (7 time slots per day)
- **Date Range**: September 2026 (30 days)

### Training Rows
- **Slot Aggregations**: 489 rows (one per unique centre + date + hour combination)
- **Train/Test Split**: 391 train / 98 test (80/20, stratified)

### Features Used
| Feature | Type | Description |
|---------|------|-------------|
| centre_id | Categorical | Procurement centre identifier (encoded) |
| hour | Numeric | Time slot hour (9, 10, 11, 14, 15, 16) |
| day_of_week | Numeric | Day of week (0=Mon, 6=Sun) |
| month | Numeric | Month of year |
| dominant_crop | Categorical | Most common crop in the slot (encoded) |
| season | Categorical | Agricultural season: Kharif/Rabi/Zaid (encoded) |
| avg_quantity | Numeric | Average quantity per booking in the slot |

### Target Variable
- **Congestion Level**: Classified from booking_count per slot
  - LOW: booking_count ≤ 1
  - MODERATE: booking_count = 2
  - HIGH: booking_count > 2

### Estimated Waiting Time
Calculated from:
- Predicted congestion level
- Current booking count
- Slot capacity
- Average procurement time (12 minutes per farmer)

Formula: `wait = booking_count × 12 × 0.5` (capped at slot_capacity × 12)

## 7. FALLBACK

### ML Unavailable Handling
If the ML model is unavailable or prediction fails:

1. **API**: Returns graceful fallback with `model_available: false`
2. **Frontend**: Shows "AI prediction temporarily unavailable."
3. **Booking count and slot capacity** are still displayed
4. **ML failure NEVER blocks booking** — farmer can still select and book slots

### Fallback Behavior
